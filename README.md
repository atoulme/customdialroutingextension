# Custom Dial Routing Extension

This extension allows an advanced behavior of the OpenTelemetry Collector where an operator can now configure a HTTP client or gRPC client to dial out via a specific network interface.a

This is meant as much of an example of use of the Dialer extension allowed in the collector configuration as a practical use case.

Please offer feedback in issues. This repository is likely short-lived and eyeing a contribution to the OpenTelemetry Collector Contrib repository.a
